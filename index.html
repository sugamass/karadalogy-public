karadalogy-pipeline

A personal tool for publishing videos to the YouTube channel カラダロジー【人体のふしぎ解説】

What it is

karadalogy-pipeline is a command-line tool that runs on the developer's own macOS machine. It produces educational videos about human physiology and publishes them to the developer's own YouTube channel.

It is a personal tool. It has no user interface, no hosted service, and no users other than its developer. It is not distributed, sold, or made available to any third party.

Uses YouTube API Services

This application uses YouTube API Services. It accesses only the developer's own channel, for the following operations:

OperationAPI method
Upload a video created by the developervideos.insert
Set the thumbnail for that videothumbnails.set
Add the video to the developer's own playlistplaylistItems.insert
Post a comment on the developer's own videocommentThreads.insert
Read view, like and comment counts for the developer's own videosvideos.list

No data belonging to any other user or channel is accessed, collected, or stored.

The channel

カラダロジー【人体のふしぎ解説】 publishes Japanese-language explanations of everyday physiological phenomena — yawning, chills, waking up — sourced from peer-reviewed literature. Every video is researched, written, and illustrated individually, and every description lists the literature actually cited, with DOIs.
