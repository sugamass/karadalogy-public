Privacy Policy

karadalogy-pipeline  /  Last updated: 2026-09-08

1. About this tool

karadalogy-pipeline ("the Tool") is a personal command-line tool created by an individual developer to operate their own YouTube channel, カラダロジー【人体のふしぎ解説】. It is not distributed to or used by any third party. It runs only on the developer's own machine.

2. Information collected

Through YouTube API Services, the Tool accesses only information about the developer's own YouTube channel and its videos:

  • Basic channel information (channel name, channel ID)
  • The ID, privacy status, and metadata of videos uploaded by the Tool
  • View counts, like counts, and comment counts for those videos

No personal information, viewing history, or any other data belonging to third parties is collected.

3. Purpose of use

  • Uploading videos produced by the developer to the developer's own channel
  • Setting thumbnails, adding videos to playlists, and posting comments on those videos
  • Recording post-publication metrics to inform the choice of future video topics

4. Storage and deletion

Collected information is stored only in local files on the developer's own machine. It is not transmitted to any external server, stored in the cloud, or accumulated in any database. Stored information is deleted at the developer's discretion at any time.

OAuth 2.0 tokens used for authentication are stored only on the developer's own machine and are never transmitted elsewhere.

5. Disclosure to third parties

Collected information is never provided, sold, or shared with any third party. It is not used for advertising purposes.

6. Use of YouTube API Services

The Tool uses YouTube API Services. By using the Tool, the following apply:

  • YouTube Terms of Service
  • Google Privacy Policy

Access granted to the Tool can be revoked at any time via the Google account security settings.
